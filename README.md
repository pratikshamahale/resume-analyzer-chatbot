# Resume Analyzer Chatbot 🤖

## 📌 About Project
This project is an AI-based Resume Analyzer Chatbot that analyzes resumes and gives smart feedback using NLP and machine learning.

## ⚙️ Features
- Resume parsing
- Skill extraction
- AI feedback
- Chatbot interface

## 🚀 Tech Stack
- Python
- NLP
- Machine Learning

## 🎯 Goal
To help users improve their resumes for better job opportunities.
